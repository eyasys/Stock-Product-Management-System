# Stock Product Management System

A Java-based inventory and stock management system designed to manage products, stock levels, supplier transactions, and sales operations.

## Features

* Product Management
* Inventory Monitoring
* Sales Transactions
* Supplier Management
* CRUD Operations

* `database/` - SQL database scripts
